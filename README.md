# Himanshi-baid

Next.js (App Router) frontend configured to work with Directus as CMS backend.

## Run locally

```bash
yarn dev
```

App runs on port `9090`.

## Environment

Copy `.env.example` to `.env.local` and fill secrets.

## Quality checks

```bash
yarn lint
yarn typecheck
yarn test
```
