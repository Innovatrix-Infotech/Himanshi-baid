# Definition of Done

## Engineering

- Feature works locally on a clean install
- Lint and type checks pass
- Relevant tests are added and passing
- No skipped tests (`describe.skip`, `it.skip`, `test.skip`, `xdescribe`, `xit`, `@Skip`)

## Documentation

- Product behavior documented in `docs/`
- Architectural changes captured via ADR when required
- Any shortcut logged in tech debt register

## Delivery

- CI is green
- PR targets `development`
- Branch is rebased/updated before merge
